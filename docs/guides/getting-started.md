# Getting Started

!!! warning "Unverified, copied by reference"
    The steps live in the [engine README](https://github.com/Heliogrim/Heliogrim-Engine#getting-started) and have not been run for this page. Treat the README as the source and report differences as a [docs error](../contribute/propose-a-change.md).

The README lists, as of commit `c50d343`:

- **Prerequisites**: a C++23 compiler (`gcc`, `clang` or `msvc`), CMake, Git with Git LFS, a graphics driver with a dedicated GPU.
- **Steps**: clone, set up Git LFS, adjust `Options.cmake`, configure with CMake and Ninja, then build the `Heliogrim`, `Editor` and test targets.

Open points before this becomes a real guide: a verified clean-machine run per OS, the supported toolchain versions, and what a first launch looks like. The README has no usage section yet.
