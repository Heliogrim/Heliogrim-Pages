## How the pieces fit

- **Issues** in the engine repository carry bugs, features and tasks, and the specs for work in flight.
- **The project board** at organisation level groups issues from every repository by status.
- **This site** holds the lasting reasoning: explorations, designs and [decisions](../adr/README.md).

An issue that turns out to need a decision gets an ADR here, and the issue links to it.
