## Which tracker

| You want to | Where | Tracker |
|-------------|-------|---------|
| Report an engine or editor defect | [Report a bug](report-a-bug.md) | Engine repository issues |
| Ask for a feature or a task | [Request a feature](request-a-feature.md) | Engine repository issues |
| Propose a decision | [Propose a change](propose-a-change.md) | Engine repository issues |
| Request an exploration | [Propose a change](propose-a-change.md) | Pages repository issues |
| Fix an error in these docs | **Edit this page** (pencil icon on every page) | Pages repository pull request |

Search existing issues before opening a new one. A duplicate costs the maintainers more than a comment on the original.
